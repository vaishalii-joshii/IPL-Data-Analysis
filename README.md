# 🏏 IPL Data Analysis

## Overview
Exploratory Data Analysis (EDA) of IPL matches (2008–2017) to understand team performance, toss impact and match patterns.

## Files
- `IPL_Data_Analysis_Case_Study.ipynb` – Full EDA on the matches dataset (univariate, bivariate, multivariate)
- `IPL_Deliveries_Analysis.ipynb` – Analysis of ball-by-ball deliveries data
- `Python_Fundamentals.ipynb` – Python basics practice
- `matches.csv`, `deliveries.csv` – Datasets

## Key Insights
- Mumbai Indians are the most successful team with 92 wins.
- Toss winners won only 51.1% of matches, so the toss gives a slight edge.
- Teams increasingly chose to field first over the years.
- About 53% of matches were won by the chasing team.

## Tools Used
Python, Pandas, NumPy, Matplotlib, Seaborn, Google Colab
